CHATGPT SETUP GUIDE

在网页中创建 MCP

按照顺序完成。不同套餐或工作空间的入口名称可能略有区别。

1

在 OpenAI Platform 创建 Tunnel

打开 Tunnels 管理页面，创建专用于 Coding Tools MCP 的 Tunnel，然后复制它的 tunnel_... 标识。

platform.openai.com / Tunnels
Tunnel name
Coding Tools MCPActive
Tunnel IDtunnel_••••••••••••
2

创建 Runtime API Key

为运行时创建独立 API Key。不要使用管理员密钥，也不要把密钥发送给任何人。

正确做法

在本助手“一键部署”页面中粘贴，保存后由 Windows 加密，日志中不会出现明文。

3

回到助手完成部署

选择工作目录，填写 Tunnel ID 和 Runtime Key，点击“保存并开始部署”。状态全部变绿后再进行下一步。

工作目录→MCP→Tunnel→已连接
4

在 ChatGPT 创建自定义连接器

进入“设置 → 连接器/Apps”，启用开发者模式并创建自定义 MCP。选择刚才建立的 Tunnel，并完成账户确认。
